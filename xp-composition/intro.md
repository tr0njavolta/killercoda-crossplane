# Welcome to Crossplane Composition with KCL

In this scenario, you'll apply a single custom resource and watch **Crossplane Composition** generate a full set of Kubernetes resources automatically.

## What You'll Do

- Apply an `App` resource and explore everything Crossplane creates
- Understand the CompositeResourceDefinition (XRD) that registers the custom API
- Read the KCL code that produces all the Kubernetes resources under the hood
- See the composition react to live changes

## Setup

The environment is being prepared automatically:
- Installing Crossplane v2
- Installing the KCL composition function
- Creating the CompositeResourceDefinition (XRD)
- Creating the Composition with KCL logic

Once you see "Setup Complete!" you're ready to go!
